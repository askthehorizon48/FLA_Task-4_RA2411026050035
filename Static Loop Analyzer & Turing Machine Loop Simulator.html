Reduction Proof & Computability Classification

Mapping Reduction: $A_{\text{TM}} \le_m \text{LOOP}_{\text{TM}}$

To prove $\text{LOOP}_{\text{TM}}$ is undecidable, we reduce the known undecidable Halting Problem $A_{\text{TM}}$ to it.

Algorithm H(<M, w>):
1. Build M' that runs M on w.
2. If M accepts w → M' halts.
3. If M rejects w → M' enters infinite loop.
4. Run LOOP_DECIDER(<M', w>).
5. If LOOP_DECIDER accepts → REJECT <M,w>.

Arithmetical Hierarchy Spectrum

  • Decidable (R): Loop-bounded programs without recursion, DFA/NFA membership.
  • Recognizable (RE): $HALT_{\text{TM}}$ (halts if it accepts, loops infinitely if not).
  • Co-RE: $LOOP_{\text{TM}}$ (recognizable only when it loops infinitely).
